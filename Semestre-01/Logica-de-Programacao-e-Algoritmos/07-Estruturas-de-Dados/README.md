# Estruturas de Dados: Listas, Tuplas, Dicionários e Strings

Este módulo aborda o armazenamento e a manipulação de coleções de dados em Python, permitindo organizar informações complexas de forma eficiente.

## Conteúdo Prudente e Aplicado:

### 1. Listas (`list`)
* Criação, indexação e mutabilidade de coleções ordenadas.
* Adição e manipulação de elementos utilizando métodos nativos (`append`, índices).

### 2. Tuplas (`tuple`)
* Utilização de coleções imutáveis para dados estáticos e constantes de sistema.

### 3. Dicionários (`dict`)
* Modelagem de registros estruturados baseados em pares de chave e valor (`key-value`).

### 4. Manipulação de Strings
* Operações de fatiamento (*slicing*), contagem de caracteres e formatação textual (`upper`, `lower`, `len`).
