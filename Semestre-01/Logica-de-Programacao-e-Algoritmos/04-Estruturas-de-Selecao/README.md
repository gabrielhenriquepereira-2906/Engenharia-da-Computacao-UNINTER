# Estruturas de Seleção ou Decisão

Este módulo aborda a introdução aos desvios condicionais em Python, permitindo que os algoritmos deixem de ser estritamente sequenciais e passem a tomar decisões com base em condições lógicas.

## Conteúdo Prudente e Aplicado:

### 1. O Comando `if` Simples
* Utilização de blocos indentados para execução condicional.
* Avaliação de expressões booleanas (`True`/`False`) para validação de fluxos (ex: verificação de maioridade para CNH).

### 2. Estrutura Composta (`if-else`)
* Introdução ao desvio alternativo para quando a condição principal não é atendida (ex: aprovação ou reprovação baseada em notas).

### 3. Estrutura Encadeada (`if - elif - else`)
* Tratamento de múltiplas escolhas e faixas de valores em sequência (ex: verificação de condições climáticas).

### 4. Aplicação Prática: Calculadora de IMC
* Integração de conceitos aprendidos anteriormente (`input`, conversão de tipos com `float`, operadores aritméticos e potenciação) com estruturas de seleção encadeadas para classificação de massa corporal.
