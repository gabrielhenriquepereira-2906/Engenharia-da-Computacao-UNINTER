# Funções e Modularização

Este módulo aborda a criação de blocos de código reutilizáveis em Python, permitindo a divisão de problemas complexos em sub-rotinas organizadas.

## Conteúdo Prudente e Aplicado:

### 1. Definição e Chamada de Funções (`def`)
* Introdução à sintaxe de criação de sub-rotinas e encapsulamento de lógica utilizando a palavra-chave `def`.

### 2. Parâmetros e Argumentos
* Envio de dados dinâmicos para dentro das funções para personalização de execuções.

### 3. Retorno de Valores (`return`)
* Utilização do comando `return` para devolver resultados processados ao escopo principal do programa.

### 4. Aplicação Prática: Modularização de Lógica
* Desenvolvimento de funções aplicadas a cálculos estatísticos (média aritmética) e tomada de decisões lógicas (verificação de maioridade).
