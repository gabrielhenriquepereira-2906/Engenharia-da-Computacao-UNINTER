# Algoritmos Iterativos e Estruturas de Repetição

Este módulo aborda o uso de laços de repetição (loops) em Python, permitindo a automação de blocos de instrução, tratamento de coleções de dados e controle de fluxo iterativo.

## Conteúdo Prudente e Aplicado:

### 1. O Laço `for` (Para)
* Utilização da função `range()` para controle determinístico de iterações (contagens progressivas e regressivas).
* Iteração direta sobre sequências de caracteres e strings (ex: varredura da palavra "UNINTER").

### 2. O Laço `while` (Enquanto)
* Aplicação de laços baseados em condições lógicas dinâmicas para cenários onde o número de repetições não é pré-definido.

### 3. Exemplo Prático: Sistema de Média de Notas com Validação
* Integração de comandos de entrada (`input`), estruturas de seleção (`if-elif-else`), controle de fluxo (`break`, `continue`) e variáveis acumuladoras para cálculo estatístico de notas de uma turma.
